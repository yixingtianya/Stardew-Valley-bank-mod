## 1. 设计哲学

本 Mod 不模拟现实银行，而是围绕星露谷的农业经济创造一套平行的高风险高回报金融系统。

**核心原则：**
- 利率锚定作物真实日回报率，而非凭空捏造
- 固定公司提供低息安全融资，动态公司提供高息风险收益
- 风险来自公司倒闭导致存款清零
- 玩家通过主动经营（售卖、打压、注资）影响利率
- 完善的破产保护机制防止玩家永久失去翻盘能力
- 债券交易机制创造金融战套利空间

## 3. 固定公司（皮埃尔 & Joja）

固定公司永远不会倒闭，是金融系统的稳定锚。

### 3.1 基础利率

| 公司 | 基础存款日利率 | 基础贷款日利率 | 锚定说明 |
|------|---------------|---------------|----------|
| 皮埃尔 | **3.0%** | **5.0%** | 对标防风草回报率，极低息 |
| Joja | **5.0%** | **8.0%** | 略高于皮埃尔，仍属低息 |

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 皮埃尔存款日利率 | 2.0% | 1.0% ~ 6.0% |
| 皮埃尔贷款日利率 | 3.0% | 2.0% ~ 8.0% |
| Joja 存款日利率 | 3.0% | 2.0% ~ 10.0% |
| Joja 贷款日利率 | 5.0% | 4.0% ~ 12.0% |

### 3.2 存款与贷款上限

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 皮埃尔存款上限 | 1,000,000g | 100,000g ~ 10,000,000g |
| 皮埃尔贷款上限 | 200,000g | 50,000g ~ 1,000,000g |
| Joja 存款上限 | 2,000,000g | 100,000g ~ 10,000,000g |
| Joja 贷款上限 | 300,000g | 50,000g ~ 1,000,000g |

### 3.3 还款机制

- 贷款时选择还款周期：**7天** 或 **14天**
- 到期日自动从身上现金扣除当期应付总额
- 利息按日计算，还款日统一结算

## 4. 动态公司（流动公司）

动态公司由玩家售卖行为触发生成，对应具体作物，会受市场影响而倒闭。

### 4.1 生成条件

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 生成所需累计出售数量 | 50个 | 10 ~ 500个 |
| 连续售卖判定窗口 | 7天 | 3 ~ 14天 |

玩家通过出货箱累计卖出某作物达阈值后，对应动态公司自动生成。

### 4.2 基础利率（锚定作物日回报率）

动态公司利率直接与对应作物的日回报率（R）绑定：

```
基础存款日利率 = R × 存款系数
基础贷款日利率 = min(R × 贷款系数, 贷款硬上限)
```

**作物日回报率速查表（保守估算）：**

| 作物 | 种子成本 | 生长周期 | 期望产出 | 日回报率 R |
|------|---------|---------|---------|-----------|
| 防风草 | 20g | 4天 | 35g | ~15.0% |
| 土豆 | 50g | 6天 | 100g | ~12.2% |
| 草莓 | 100g | 8+4天 | 120g/次 | ~6.3% |
| 蓝莓 | 80g | 13+4天 | 150g/次 | ~7.2% |
| 蔓越莓 | 240g | 7+5天 | 150g/次 | ~4.2% |
| 啤酒花 | 60g | 11+1天 | 25g/天 | ~3.5% |
| 杨桃 | 400g | 13天 | 750g | ~4.9% |
| 上古水果 | 500g | 28+7天 | 550g | ~9.1% |

**锚定系数：**

| 系数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 存款系数 | 1.0 | 0.5 ~ 1.2 |
| 贷款系数 | 1.5 | 1.0 ~ 2.0 |
| 贷款日利率硬上限 | 15% | 10% ~ 20% |

**示例：**

| 动态公司 | R | 存款日利率 | 贷款日利率 |
|---------|---|-----------|-----------|
| 土豆公司 | 12.2% | 12.2% | 15%（触上限） |
| 蓝莓公司 | 7.2% | 7.2% | 10.8% |
| 杨桃公司 | 4.9% | 4.9% | 7.35% |

### 4.3 日还利息（强制）

动态公司贷款**每日凌晨自动从玩家现金扣除利息**。若不足则进入利息欠债状态。

### 4.4 贷款上限与作物价值绑定

| 作物类别 | 贷款上限 | 示例 |
|----------|---------|------|
| 低价（种子<100g） | 50,000g | 土豆、防风草、蓝莓 |
| 中价（100~200g） | 80,000g | 草莓、啤酒花 |
| 高价（>200g） | 100,000g | 杨桃 |

### 4.5 初始存款上限

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 动态公司初始存款上限 | 500,000g | 100,000g ~ 5,000,000g |

## 5. 利率浮动系统

### 5.1 运气影响（所有公司）

`实际日利率 = 基础利率 × (1 ± 运气值 × 运气强度系数)`

- 存款：运气↑ → 利率↑
- 贷款：运气↑ → 利率↓

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 运气强度系数 | 2.5 | 1.0 ~ 5.0 |

**示例（皮埃尔存款 3%，运气 +0.07）：**
`= 3% × (1 + 0.07 × 2.5) = 3.525%`

### 5.2 天气影响（所有公司）

日利率绝对值加成，在运气乘数前叠加。

| 天气 | 皮埃尔加成 | Joja加成 | 动态公司（农业类） |
|------|-----------|---------|-------------------|
| 晴天 | 0% | +0.01% | 0% |
| 雨天 | +0.02% | -0.01% | +0.05% |
| 风暴 | -0.05% | 0% | -0.10% |
| 雪天 | -0.01% | +0.01% | 0% |

| 参数 | 允许范围 |
|------|----------|
| 各天气加成 | 0% ~ ±0.20% |

### 5.3 连续售卖加成（动态公司专属）

玩家每日通过出货箱售卖对应商品：

| 连续售卖天数 | 存款利率加成 | 贷款利率加成 |
|-------------|-------------|-------------|
| 每连续 1 天 | +0.5% | +1.0% |
| 上限 | +5.0% | +10.0% |

停止售卖后，每日衰减：
- 存款：-0.5%/天
- 贷款：-1.0%/天

### 5.4 竞争打压（动态公司专属）

向皮埃尔/Joja 直接出售对应商品：

| 单日出售数量 | 存款利率下降 | 贷款利率下降 |
|------------|-------------|-------------|
| 1~10 个 | -0.2% | -0.4% |
| 11~30 个 | -0.5% | -1.0% |
| 31~50 个 | -1.0% | -2.0% |
| 50+ 个 | -2.0% | -4.0% |

效果持续 5 天，可叠加（上限 3 层）。

### 5.5 负利率

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 允许负利率 | true | false / true |
| 存款利率下限 | -2.0%/天 | -5.0% ~ 0% |

## 7. 贷款与还款机制

### 7.1 固定公司还款

- 贷款时选择周期：**7天** 或 **14天**
- 到期日自动从现金扣除：本金 × 利率 × 天数 + 可选还本部分
- 玩家可在还款日前手动提前还款

**还款周期对利率的影响：**
- 14天周期比7天周期利率**低 0.5%**（鼓励长期稳定借贷）

| 参数 | 推荐值 |
|------|--------|
| 14天周期利率折扣 | 0.5% |

### 7.2 动态公司还款

- **每日凌晨自动扣息**
- 本金在还款日统一偿还（或提前）
- 不设宽限期

## 8. 破产与欠债系统

### 8.1 判定流程

```
扣息日 / 还款日
    │
    ├─ 现金足够 ──→ 正常支付
    │
    └─ 现金不足
          │
          ├─ 存款总额 ≥ 应还金额 ──→ 欠债状态
          │       │
          │       ├─ 利息欠债（每日扣息失败）
          │       └─ 本金欠债（还款日失败）
          │
          └─ 存款总额 < 应还金额 ──→ 破产状态
```

### 8.2 利息欠债（动态公司每日扣息失败）

**判定：** 每日凌晨扣息时现金不足。

**规则：**

| 项目 | 单利模式（推荐） | 复利模式 |
|------|----------------|---------|
| 未付利息处理 | 记录到逾期利息账户，不滚入本金 | 未付利息加入本金 |
| 逾期利息生息 | 否 | 是（利滚利） |
| 后续利息 | 按原本金继续计算 | 按新本金计算 |
| 宽限期 | 无 | 无 |
| 强制扣款 | 无 | 无 |

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 利息欠债计息方式 | 单利 | 单利 / 复利 |

**后果：**
- 逾期利息累积，在还款日或债券交易时一并结算
- 增加后续还款压力
- 不影响借款/取款功能（未触发破产线前）

### 8.3 本金欠债（还款日支付失败）

**判定：** 还款日现金不足，但存款总额 ≥ 应还总额。

**规则：**

| 项目 | 设定 |
|------|------|
| 宽限期 | 1 天（可配置 0~3 天） |
| 宽限期内利息 | 继续计算 |
| 宽限期结束未还 | 从存款强制划扣（低利率账户优先） |
| 罚息 | 基础利率 +20%（可配置 0%~50%） |
| 扣款顺序 | 优先逾期利息 → 正常利息 → 本金 |

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 本金欠债宽限期 | 1 天 | 0 ~ 3 天 |
| 罚息幅度 | +20% | 0% ~ 50% |
| 强制扣款顺序 | 低利率优先 | 低→高 / 高→低 / 按比例 |

### 8.4 破产状态（完全无力偿还）

**判定：** 现金不足，且存款总额 < 应还总额。

**规则：**

| 处置 | 设定 |
|------|------|
| 利息计算 | **立即停止**（0%） |
| 禁止借款 | 是，所有公司 |
| 禁止取款 | 是，所有公司 |
| 收益扣除 | 每日出货收入的 **50%** 强制还债 |
| 结束条件 | 逾期债务全部偿清 |

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 破产收入扣除比例 | 50% | 20% ~ 80% |
| 破产期间利息 | 0%（停止计息） | 不可变 |
| 破产禁止借款 | 是 | 不可变 |
| 破产禁止取款 | 是 | 是 / 否 |
| 首次破产提示 | 弹窗警告 | 开启 / 关闭 |

## 9. 债券交易（金融战核心）

### 9.1 触发条件

动态公司满足任一倒闭条件后，进入**濒临破产**状态，持续 **3 天**。

| 倒闭条件 | 推荐阈值 | 允许范围 |
|----------|---------|----------|
| 连续无出货交易 | 14 天 | 7 ~ 28 天 |
| 存款利率持续为负 | 5 天 | 3 ~ 14 天 |
| 玩家存款总额低于 | 5,000g | 0 ~ 50,000g |

### 9.2 债券变卖机制

濒临破产的动态公司将其持有的**所有玩家贷款合同**出售给当前贷款利率较高的固定公司。

**对贷款玩家：**

| 变化项 | 规则 |
|--------|------|
| 贷款利率 | 变为购买方当前贷款利率 × 50% |
| 利率折扣 | 可配置 30% ~ 70%，推荐 50% |
| 还款周期 | 重置为 28 天 |
| 新还款周期 | 可配置 14 ~ 56 天 |
| 债务总额 | 本金 + 所有未付利息（含逾期利息）一并打包 |
| 本金 | 不变 |

**示例：**
- 玩家欠土豆公司 50,000g + 累计未付利息 5,000g = 总债务 55,000g
- 土豆公司濒临破产，皮埃尔利率高于 Joja → 卖给皮埃尔
- 皮埃尔当前贷款利率 5% → 新利率 = 2.5%
- 还款周期变为 28 天
- 日息：55,000 × 2.5% = 1,375g（原土豆公司日息 7,500g）

### 9.3 债券交易后的公司命运

- 变卖后若资金恢复、利率转正 → 摆脱濒危，恢复正常
- 若 3 天宽限期结束时仍未恢复 → **正式倒闭**

### 9.4 倒闭清算

| 项目 | 效果 |
|------|------|
| 玩家存款 | **全额清零** |
| 玩家贷款（若未转移） | **全额清零**（赖账成功） |
| 公司状态 | 从列表移除，可重新生成 |

| 参数 | 推荐值 | 允许范围 |
|------|--------|----------|
| 濒临破产宽限期 | 3 天 | 1 ~ 7 天 |
| 债务转移利率折扣 | 50% | 30% ~ 70% |
| 债务转移后新还款周期 | 28 天 | 14 ~ 56 天 |
| 债务转移包含项目 | 本金+逾期利息+正常未付利息 | 不可变 |
| 债券购买方选择 | 当前贷款利率较高的固定公司 | 不可变 |

## 10. 套利闭环示例

以下是一个完整的金融战操作流程，展示各机制的相互作用：

**起始条件：**
- 皮埃尔存款日利率 3.0%，贷款日利率 5.0%
- Joja 存款日利率 5.0%，贷款日利率 8.0%
- 已生成土豆公司，存款日利率 12.2%，贷款日利率 15%（触上限）

**操作步骤：**

**第 1 步：从土豆公司贷款**
- 贷款 50,000g，日息 7,500g
- 日付利息压力极大，短期操作

**第 2 步：存入皮埃尔**
- 将 50,000g 存入皮埃尔公司
- 皮埃尔日息收入：50,000 × 3% = 1,500g/天

**第 3 步：打压土豆公司**
- 每日去皮埃尔购买/出售大量土豆（不要出货箱卖出）
- 每次打击土豆公司存款利率 -0.5% ~ -2%
- 持续 5 天效果叠加

**第 4 步：土豆公司濒临破产**
- 因利率持续为负或存款枯竭，进入 3 天濒危期
- 公司将债务卖给皮埃尔（皮埃尔利率高于被打压后的 Joja）

**第 5 步：债务重组**
- 转移后：贷款利率 5% × 50% = 2.5%
- 日息变为：50,000 × 2.5% = 1,250g
- 还款周期延长为 28 天

**第 6 步：套利达成**
- 皮埃尔存款日收入：1,500g
- 皮埃尔贷款日支出：1,250g
- **日净赚：250g 无风险套利**
- 28 天后还清贷款，存款仍在生息
- 若期间再操作其他公司，收益翻倍

**可选后续：**
- 若土豆公司 3 天后倒闭，当初若未转移的贷款会被清零
- 但已转移给皮埃尔的债务必须偿还
- 玩家可选择赖账路线（不转移，等公司倒闭），但存款也会清零

## 借款上限与玩家资产绑定机制

### 设计逻辑

借款上限不再是固定值，而是与玩家的**净资产**挂钩。净资产越高，能借的钱越多；净资产为负或破产时，借款功能直接锁死。

**净资产公式：**
```
净资产 = 身上现金 + 所有银行存款总额 - 所有贷款总额（含逾期利息）
```

### 借款上限计算

```
借款上限 = 净资产 × 借款杠杆系数
```

| 参数 | 推荐值 | 允许范围 | 说明 |
|------|--------|----------|------|
| 借款杠杆系数 | 200% | 100% ~ 500% | 净资产 100,000g 时最多可借 200,000g |
| 借款上限硬封顶 | 500,000g | 100,000g ~ 2,000,000g | 防止后期过度膨胀 |

**示例：**
- 玩家 A：现金 5,000g，存款 50,000g，贷款 0g → 净资产 55,000g → 可借 110,000g
- 玩家 B：现金 500g，存款 0g，贷款 30,000g → 净资产 -29,500g → 无法借款
- 玩家 C：现金 200,000g，存款 500,000g，贷款 100,000g → 净资产 600,000g → 可借 1,200,000g，但受硬封顶限制，只能借 500,000g

### 各公司额度分配

总借款上限由净资产决定后，在各公司之间的分配规则：

| 参数 | 推荐值 | 允许范围 | 说明 |
|------|--------|----------|------|
| 固定公司与动态公司额度比例 | 固定公司占 60%，动态公司占 40% | 可配 | 保证低息渠道有足够额度 |
| 各公司实际可用额度 | 从总上限中扣除已借款金额后分配 | 不可变 | 动态计算 |

**分配逻辑示例（净资产 100,000g，总上限 200,000g）：**
- 固定公司共享额度：120,000g
- 动态公司共享额度：80,000g
- 若已在皮埃尔借了 50,000g，剩余固定公司额度：70,000g
- 若已在土豆公司借了 30,000g，剩余动态公司额度：50,000g

---

### 破产状态下的借款限制

| 状态 | 是否可以借款 |
|------|-------------|
| 正常状态 | 是，受净资产上限约束 |
| 利息欠债 | 是（未触及破产线） |
| 本金欠债宽限期内 | **否**（违约边缘，禁止新增借款） |
| 破产状态 | **否**（完全锁死，直到逾期债务偿清） |

**本金欠债宽限期内的借款锁定：**
- 还款日到期，进入宽限期后，该玩家的**所有借款功能立即暂停**。
- 若宽限期内凑够钱还款，恢复正常。
- 若宽限期结束被强制划扣或转入破产，继续锁定。

---

### 配置参数总表

| 参数 | 推荐值 | 允许范围 | 说明 |
|------|--------|----------|------|
| 借款杠杆系数 | 200% | 100% ~ 500% | 净资产乘数 |
| 借款上限硬封顶 | 500,000g | 100,000g ~ 2,000,000g | 绝对上限 |
| 固定公司额度占比 | 60% | 50% ~ 80% | 剩余分配给动态公司 |
| 净资产更新频率 | 每次借款前实时计算 | 不可变 | |
| 利息欠债是否禁止借款 | 否 | 否 / 是 | 可选配置 |
| 本金欠债宽限期禁止借款 | 是 | 不可变 | |
| 破产状态禁止借款 | 是 | 不可变 | |

---

这套机制确保：
- 玩家借的钱始终在自己偿还能力范围内
- 老赖（高负债、低资产）无法再借新债
- 多人模式下无法通过破产转移大额资金
- 正常经营的玩家不受影响，杠杆空间充足

## 动态公司借款上限与利率绑定机制

### 设计逻辑

动态公司的借款上限由两个维度共同决定：

1. **作物价值等级**：决定基础额度天花板（之前已设计）
2. **当前存款利率**：决定当前可用额度的比例

```
实际可用借款额度 = 作物基础额度 × 利率健康系数
```

### 利率健康系数

以公司当前存款日利率为基准，映射到 0% ~ 100% 的额度比例：

| 存款日利率状态 | 利率健康系数 | 说明 |
|--------------|-------------|------|
| ≥ 基础利率（健康） | **100%** | 全额可借 |
| 基础利率的 50% ~ 100% | **50% ~ 100%** | 线性递减 |
| 0% ~ 基础利率的 50% | **10% ~ 50%** | 大幅紧缩 |
| ≤ 0%（衰退/负利率） | **0%** | 完全无法借款 |

**公式：**

```
若 日利率 ≥ 基础利率：
    健康系数 = 100%

若 0% < 日利率 < 基础利率：
    健康系数 = 10% + 90% × (日利率 / 基础利率)

若 日利率 ≤ 0%：
    健康系数 = 0%
```

### 实际借款额度示例

以土豆公司为例（低价作物，基础额度 50,000g，基础存款日利率 12.2%）：

| 土豆公司当前存款日利率 | 状态 | 健康系数 | 实际可借额度 |
|----------------------|------|---------|-------------|
| 17.2%（满连续售卖加成） | 极繁荣 | 100% | **50,000g** |
| 12.2%（基础利率） | 正常 | 100% | **50,000g** |
| 6.1%（被打压至一半） | 衰退 | 55% | **27,500g** |
| 2.0%（严重衰退） | 危险 | 24.8% | **12,400g** |
| 0% | 濒死 | 0% | **0g** |
| -1.0%（负利率） | 濒死 | 0% | **0g** |

玩家越想打压一家公司使其倒闭，该公司能提供的借款就越少。无法在濒死公司身上薅最后一笔羊毛。

---

### 借款时机的策略意义

**健康公司（利率高）：**
- 能借满额，但利率高（日付利息压力大）
- 适合短期周转或准备金融战（借钱后反转打压）
- 公司健康，倒闭风险低，赖账难

**衰退公司（利率低）：**
- 借款额度受限，借不到大钱
- 贷款利率也低（因为利率锚定），但额度紧缩让套利空间有限
- 公司濒死，赖账容易但借不到多少

**策略选择：**
- 如果想赖账，只能赖掉小额——不值得
- 如果想套利，必须在公司健康时借，然后通过连续售卖维持甚至推高利率，把公司养肥了再决定割还是养
- 金融战的正确姿势：**养肥公司 → 借满额度 → 反转打压 → 债券转移套利**，而非直接弄死赖账

---

### 与全局借款上限的关系

玩家最终能从某家动态公司借到的金额，取以下三者的**最小值**：

1. 全局借款上限（净资产 × 杠杆系数，受限硬封顶）
2. 该公司作物等级基础额度
3. 该公司当前额度（基础额度 × 利率健康系数）

**示例：**
- 玩家净资产 100,000g，全局上限 = 200,000g
- 动态公司总池子 = 200,000g × 40% = 80,000g
- 土豆公司基础额度 = 50,000g
- 土豆公司当前利率 = 6.1%，健康系数 = 55%
- 土豆公司当前可用 = 50,000g × 55% = 27,500g
- 最终可借：min(80,000g, 50,000g, 27,500g) = **27,500g**

---

### 配置参数

| 参数 | 推荐值 | 允许范围 | 说明 |
|------|--------|----------|------|
| 利率健康系数下限（利率≥基础时） | 100% | 不可变 | 健康公司全额可借 |
| 利率健康系数下限（利率>0但<基础） | 10% | 0% ~ 20% | 衰退但未负时的最低比例 |
| 利率≤0时健康系数 | 0% | 不可变 | 负利率直接禁借 |
| 健康系数计算公式 | 线性插值 | 线性 / 阶梯 / 自定义曲线 | |

---

### 总结

这套机制确保：
- 越健康的公司越能借钱，越濒死的公司越难借钱
- 玩家无法通过“预判倒闭 → 大额借款 → 赖账”的方式套利
- 金融战的正确路径是“养公司 → 借钱 → 打压 → 债券转移套利”，而非直接弄死赖账
- 利率本身成为债务博弈的核心指标，与公司经营深度绑定
