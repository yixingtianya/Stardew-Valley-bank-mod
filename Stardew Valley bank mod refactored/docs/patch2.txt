一、核心修正摘要

本补丁重构了饥饿期和濒死期的玩家操作限制，解决旧版“禁止取款”的逻辑矛盾，并引入“资产池取款限制”“入股救市”“复活稳定性”“贷款上限状态乘数”四项关联机制。

旧规则（value2.docx §5原文）：

状态 取款 注资救市
饥饿期 冻结 允许（无额度限制）
濒死期 冻结 允许（限制额度）

新规则（本补丁替换）：

状态 存款 取款 借贷 注资救市 救活条件
饥饿期 正常 限制取款（≤ 公司资产池余额） 禁止 不允许 燃料满足率 ≥ 80%
濒死期 正常 限制取款（≤ 公司资产池余额） 禁止 允许（上限 = 原始贷款上限×50%，复活后翻倍计入存款本金） 燃料满足率 ≥ 30%（7天窗口）
复活后 正常 正常 正常 - 燃料满足率重置为 100%（稳定期中部）

二、逐项修正内容

2.1 贷款上限状态乘数

定义：

公司的原始贷款上限受当前状态影响，形成有效贷款上限。
有效贷款上限 = 原始贷款上限 × 状态乘数

状态乘数表：

状态 利率乘数 燃料需求系数 贷款上限乘数
繁荣期 / 稳定期 ×1.2 / ×0.9 ×1.0 / ×0.8 ×1.0（基准不变）
饥饿期 ×0.7 ×0.5 ×0.6
濒死期 ×0.4 ×0.3 ×0.3

设计逻辑：

· 繁荣期和稳定期：贷款上限维持原值，健康公司拥有完整放贷能力。
· 饥饿期（×0.6）：货源紧张，公司收紧贷款审批，放贷能力大幅缩水。
· 濒死期（×0.3）：公司自身难保，几乎没有放贷能力。这与濒死期“禁止借贷”的规则形成双层保险——即使未来某个规则变体允许濒死期借贷，能借到的金额也极为有限。

配置参数：

参数 默认值 允许范围
饥饿期贷款上限乘数 0.6 0.3 ~ 0.8
濒死期贷款上限乘数 0.3 0.1 ~ 0.5

2.2 公司资产池

定义：

```
有效贷款上限 = 原始贷款上限 × 状态乘数
资产池 = 有效贷款上限 − 已贷出未归还本金总额
```

资产池本质是公司尚未贷出的额度，代表公司可用于兑付取款的现金上限。公司状态越差，有效贷款上限越小，资产池越紧缩——这不是禁止取款，而是公司真的没钱了。

取款规则：

```
玩家最大取款额 = min(该玩家存款余额, 公司当前资产池余额)
```

当资产池 ≤ 0 时，钳位为 0，玩家分文取不出。

资产池变动来源：

操作 资产池变化 说明
玩家存款 不变 存款增加公司现金，但有效贷款上限不变
玩家取款 不变 取款减少公司现金，但不影响有效贷款上限和已贷出本金
玩家借款 减少 已贷出本金增加 → 资产池缩小
玩家还贷 增加 已贷出本金减少 → 资产池恢复
公司状态变化 随有效贷款上限联动 状态恶化 → 有效贷款上限缩小 → 资产池缩水
注资救市 +金额 直接注入现金，扩张资产池
每日付息 不变 利息支付不影响有效贷款上限和已贷出本金

综合实例验证： 土豆公司原始贷款上限50,000g，玩家A存款30,000g，玩家B借款20,000g。

状态 有效贷款上限 资产池 玩家A可取
稳定期（×1.0） 50,000g 30,000g 30,000g（全额）
饥饿期（×0.6） 30,000g 10,000g 10,000g（锁定20,000g）
濒死期（×0.3） 15,000g -5,000g → 0g 0g（分文取不出）

濒死期公司已资不抵债，存款形同虚设，唯有赌注复活或等待清零。

UI建议： 在公司详情页显示“公司资产池：XXX g”及“有效贷款上限：XXX g”。

2.3 饥饿期规则修正

改动：

1. 取款从“冻结”改为“限制取款（≤ 资产池余额）”
2. 贷款上限受 ×0.6 乘数影响，资产池同步缩水
3. 移除注资救市功能（仅濒死期可用）

理由： 饥饿期是高风险经营状态。贷款上限乘数 ×0.6 意味着即使公司没有大量放贷，资产池也已因状态而收缩，限制了取款空间。玩家应通过供给作物恢复公司健康，而非用钱填坑。允许注资会导致套利漏洞（详见2.4）。

2.4 濒死期规则修正 + 入股救市

改动：

1. 取款从“冻结”改为“限制取款（≤ 资产池余额）”
2. 贷款上限受 ×0.3 乘数影响，资产池通常归零
3. 注资救市重新定义为入股救市

入股救市规则：

项目 规则
可用阶段 仅濒死期（7天重组期）
注资上限 该公司原始贷款上限 × 50%（仍按原始上限计算，不受状态乘数影响）
回报方式 公司复活后，注资金额 翻倍计入该玩家的存款本金
回报生效条件 公司燃料满足率在7天内回升至 ≥ 30%，脱离濒死
失败处理 公司倒闭，注资金额与存款一并清零
复活后存款 翻倍后的存款与普通存款完全相同：享受利率、受限取款规则、承受倒闭清零风险

UI提示词（注资确认界面）：

“入股救市：注资股份将以翻倍额的形式计入存款，公司复活后生效。”

利率即分红： 翻倍后的存款本金享受公司利率，利率随公司状态波动——这就是分红。

注资对资产池的影响： 注资直接增加资产池（资产池 + 注资金额），但濒死期有效贷款上限仍为原始上限 × 0.3。例如土豆公司濒死，注资25,000g后，资产池 = 15,000 − 20,000 + 25,000 = 20,000g，玩家此时可取回部分存款。但复活前翻倍不计入——翻倍仅在复活时生效。

与2.3的联动（防套利）： 饥饿期不允许注资，确保套利闭环断裂。

注资上限为何仍按原始贷款上限计算： 入股救市是玩家在公司最低谷时的风险投资，其规模应与公司的基础体量挂钩，而非与濒死时的残值挂钩。按原始上限计算的注资上限更大，既是对承担清零风险的合理回报，也避免因濒死期贷款上限过小导致注资毫无意义。

2.5 复活后稳定性

规则：

公司脱离濒死后，燃料满足率重置为 100%（稳定期中部），公司状态为 稳定期。
复活后有效贷款上限恢复为原始贷款上限 × 1.0，资产池同步恢复。

提示词（复活时UI弹窗）：

“XX公司已脱离濒死！燃料满足率恢复至100%，进入稳定期。入股注资将以双倍注资金额的形式计入您的存款本金。”
