一、Harmony 补丁清单

  1.1 TVPatch — TV.checkForAction Prefix
  ─────────────────────────────────────────
    文件：      Patches/TVPatch.cs
    目标：      StardewValley.TV.checkForAction
    类型：      HarmonyPrefix + return false（跳过原方法）
    命名空间：  bankmod.tv
    功能：      注入 FBN 金融频道到电视选择菜单
    频道构建：  BuildChannelList() 完整镜像原版频道（Weather/Fortune/Livin'/The/Fishing/Leave + FBN）
    兼容性状态：✅ 已改造（2026-06-03）

    已知兼容性：
      - SVE（FlashShifter.SVECode）：不冲突 — SVE 未补丁 TV.checkForAction
      - 其他电视 mod（如 Custom TV）：Prefix + return false 可能阻止其他 mod 的补丁执行
      - Content Patcher 电视扩展：不冲突（CP 通过 JSON 注入，不使用 Harmony）

    改造历史：
      V1（原始）：Prefix 构建自定义频道列表，丢失了原版的 "???" 频道（Fall 26 诅咒事件）
      V2（当前）：BuildChannelList() 完整复制原版所有频道 + FBN，保留 "???" 频道

    游戏更新检查清单：
      - TV.checkForAction 方法签名是否变化
      - TV.selectChannel 方法是否变化
      - 原版频道是否新增（需同步到 BuildChannelList）
      - TV.currentChannel 字段名/类型是否变化
      - TV.screen 字段名/类型是否变化


  1.2 NpcDialoguePatch — NPC.checkAction Prefix
  ─────────────────────────────────────────────
    文件：      Patches/NpcDialoguePatch.cs
    目标：      StardewValley.NPC.checkAction
    类型：      HarmonyPrefix（不阻止原方法，通过 afterDialogues 回调追加）
    命名空间：  bankmod.npcdialogue
    功能：      欠债/破产/祝贺/NPC 对话注入
    兼容性状态：✅ 低风险

    已知兼容性：
      - SVE：不冲突 — SVE 不补丁 NPC.checkAction
      - NPC Dialogue Modifications 等对话 mod：使用 afterDialogues 追加，风险低
      - 唯一风险：多个 mod 同时使用 afterDialogues 可能产生回调竞态

    实现细节：

      - 使用 Game1.afterDialogues = () => { ... } 回调
      - 原版 NPC 对话正常播放，BankMod 对话在回调中追加


二、反射调用清单

  2.1 LetterViewerMenu.mailMessage — 信件内容注入
  ─────────────────────────────────────────────────
    文件：      BankMod.cs（MenuChanged 事件处理）
    目标类：    StardewValley.Menus.LetterViewerMenu
    目标字段：  mailMessage（private List<string>）
    反射方式：  System.Reflection（非 SMAPI ReflectionHelper）
    功能：      在信件打开时将 Data/mail 缓存中的占位内容替换为真实信件文本
    兼容性状态：✅ 已加固（2026-06-03）

    已知兼容性：
      - Content Patcher 信件扩展：不冲突 — CP 通过 Data/mail JSON 注入，不修改 LetterViewerMenu
      - 其他 mod 反射同一字段：可能互相覆盖（已加 try-catch 防御）
      - SVE 信件：不冲突 — SVE 通过 Data/mail 注入，不反射 LetterViewerMenu

    加固内容（2026-06-03）：
      1. try-catch 包裹反射操作，失败时记录日志而非崩溃
      2. 类型检查：确认当前值是 List<string>
      3. 字段不存在时日志提示 "game version may have changed"

    游戏更新检查清单：
      - LetterViewerMenu 类是否重命名或移除
      - mailMessage 字段是否存在、类型是否仍为 List<string>
      - mailMessage 的访问级别是否改变
      - LetterViewerMenu 构造函数中 mailTitle 的赋值方式是否变化

三、SVE 兼容性专题

  SVE 版本：1.15.11（源码审查日期：2026-06-03）
  SVE UniqueID：FlashShifter.SVECode

  SVE 的 Harmony 补丁（审查结论）：
    - HarmonyPatch_PiggyBank：Postfix on SObject.checkForAction（不冲突）
    - FurnitureCatalogue2Patch：Postfix on Furniture.checkForAction（不冲突）
    - 其他补丁：Mountain/Desert/Bushes 等，均与 BankMod 无交集

  SVE 对 TV 的处理：
    - SVE 未补丁 TV.checkForAction
    - SVE 通过 Content Patcher JSON 扩展内容，不使用 Harmony 修改电视

  SVE 对 Morris 的处理：
    - SVE 未控制 NPC.isInvisible
    - SVE 的 Morris 引用仅在特殊订单和山地补丁中

  BankMod 的 SVE 适配：
    - _sveLoaded 检测：Helper.ModRegistry.IsLoaded("FlashShifter.SVECode")
    - Morris 反射跳过：SVE 加载时不做 isInvisible 反射
    - 降级行为：Morris 事件过场可能出现两个 Morris（不崩溃）
