## 概述

本 Mod 为星露谷物语引入一套完整的金融市场模拟系统：

- **固定银行**：Joja 超市与皮埃尔杂货店，基础存贷服务
- **动态公司**：每种作物出货达标后自动诞生，利率由作物经济学决定
- **燃料市场**：出货补燃料 / 商店买卖扣燃料，满足率决定公司运营状态
- **利率浮动**：天气、运气、连续售卖、停售衰减、竞争对手打压五因子联动
- **破产保护**：债务违约触发，贷款冻结停息，收入强制偿债
- **电视金融频道**：每日预测利率走向，播报公司诞生与献祭路线影响
- **战略操作**：杠杆套利、囤货养司、多头对冲、做空收割

## 核心系统

### 固定公司

Joja 超市和皮埃尔杂货店，提供基础金融服务。利率稳定，适合保守配置。

| 公司 | 存款日利率 | 贷款日利率 | 存款上限 | 贷款上限 | 天气加成 |
|------|-----------|-----------|---------|---------|---------|
| Joja 超市 | 2.5% | 4.0% | 2,000,000g | 300,000g | 晴天 +0.01% |
| 皮埃尔杂货店 | 1.5% | 2.5% | 1,000,000g | 200,000g | 雨天 +0.02% |

**特点**：利率不浮动（不受售卖行为影响），存贷上限固定，适合作为资金中转站和风险对冲池。

---

### 动态公司

每种作物通过出货箱累计出售 ≥ 50 个（可配）时，自动诞生一家以该作物命名的公司。

**诞生规则**：
- 名称：作物名 + "公司"（如"土豆公司"、"蓝莓公司"）
- 基础利率：由作物 R 值经三段式公式计算（详见利率体系）
- 初始燃料：Smax × 30% + 累计出售数量 × 10 FP（上限 Smax × 200%）
- 14 天新公司保护期，期间不会触发倒闭
- 全局席位上限 4 个，单季新增上限 2 个
- 咖啡豆和向日葵不生成公司

**存款与借款**：
- 存取界面与固定公司相同
- 繁荣/稳定期：无限制
- 饥饿/濒死期：取款受资产池限制，禁止借贷

**倒闭重生**：
- 燃料耗尽 → 倒闭（债券转移 + 阶梯清算）
- 出售计数归零，跨季冷却（同季不再重生）
- 继续出货达标 → 生成全新公司，不继承前身数据

---

### 公司状态与燃料

**满足率** = FuelStock / (Smax × 10)，决定公司运营状态：

| 满足率 | 状态 | 利率乘数 | 贷款上限乘数 | 借贷 | 取款 |
|--------|------|---------|------------|:--:|:--:|
| >150% | 繁荣 | ×1.2 | ×1.0 | ✅ | ✅ |
| 80% ~ 150% | 稳定 | ×0.9 | ×0.9 | ✅ | ✅ |
| 30% ~ 80% | 饥饿 | ×0.7 | ×0.6 | ❌ | 限资产池 |
| <30% | 濒死 | ×0.4 | ×0.3 | ❌ | 限资产池 |

**燃料点 (FP)** 内部单位，1 标准作物 = 10 FP，UI 显示为 FP ÷ 10：

| 操作 | FP 变化 | 说明 |
|------|--------|------|
| 出货箱卖出 1 个 | +10 | 铱星 +20，金星 +15 |
| 商店购买 1 个 | -5 | 打压效果 |
| 商店卖出 1 个 | -5 | 与购买打压等值 |
| 每日自然消耗 | -DBase × 状态系数 | 繁荣 ×1.0，稳定 ×0.8，饥饿 ×0.5，濒死 ×0.3 |

**资产池** = 有效贷款上限 − 未还本金 − 已取额度。饥饿/濒死期取款不能超过剩余资产池。

### 利率体系

**固定公司**：利率从 config 直接读取，不受售卖行为影响。

**动态公司基础利率**（R 值公式）：
- R = 等效日收益 / 等效支出（数据源 `Crops values.txt`）
- 存款利率 = R > 20% 时 R × 0.5，0 < R ≤ 20% 时不打折（R × 1.0），R ≤ 0 时归零
- 贷款利率 = R > 20% 时 R × 0.75，否则 R × 1.5，硬上限 15%

**浮动因子（计算顺序）**：
1. 基础利率
2. + 连续售卖加成（每连续天 + 可配%，上限可配）
3. − 停售衰减（每天 − 可配%）
4. − 竞争对手打压（叠层制，≥20 个 2 层，≥50 个 3 层，每层 − 可配%/天，持续可配天）
5. × 运气倍率（LuckStrengthCoefficient）
6. + 天气加成（晴/雨/雪/雷暴，每公司独立可配）

**状态浮动的实际影响示例**（土豆公司，R ≈ 30.66%，不打折）：

| 状态 | 存款利率 | 贷款利率 | 贷款上限（存款 50,000 时） |
|------|---------|---------|--------------------------|
| 繁荣 | 36.79% | 34.49% | 50,000g |
| 稳定 | 27.59% | 25.87% | 45,000g |
| 饥饿 | 21.46% | 16.06% | 30,000g |
| 濒死 | 12.26% | 9.18% | 15,000g |

### 贷款系统

**借款**：
- 7 天或 14 天周期，14 天享利率折扣（默认 -0.5%）
- 同日同公司同周期自动合并（利率加权平均），不同日各自独立还款日
- 全局上限 = 净资产 × 杠杆系数（默认 ×2.0）
- 饥饿期 / 濒死期 / 破产保护期间禁止借款
- 借款界面提供「最大借款」一键按钮

**还款**：
- 还款顺序：逾期欠息 → 累计利息 → 本金
- 未逾期提前还款：重置到期日（续期）
- 已逾期部分还款：不重置到期日，不清除逾期状态
- 全额还清：贷款移除
- 还款界面提供「全部还款」一键按钮
- 明细视图支持逐条贷款独立还款

**利息欠债**（动态公司）：
- 每日从现金扣除贷款日息
- 现金不足 → 剩余转入 OverdueInterest，进入利息欠债
- 单利模式（默认）：逾期利息不滚入本金
- 复利模式（可配）：逾期利息滚入本金利滚利

**本金欠债**（固定公司）：
- 到期现金不足 → 宽限期（可配，默认 1 天）
- 宽限期内罚息利率（可配，默认 +20%）
- 宽限期结束 → 强制从存款划扣（现金 → 同公司存款 → 低利率存款优先）

---

### 破产保护

**触发**：贷款逾期 → 宽限期 → 强制划扣（现金 + 全部存款）→ 仍不够还 → 贷款冻结 + 进入破产。

**破产效果**：

| 项目 | 状态 |
|------|:--:|
| 冻结贷款计息 | 0%（停息） |
| 冻结贷款到期 | 无限期 |
| 借款 | ❌ 禁止 |
| 取款 / 存款 | ✅ 正常 |
| 存款利息 | ✅ 正常计算 |
| 出货收入 | 50% 强制偿债 |
| 日间收入 | 50% 强制偿债（取款/借款豁免） |
| 右下角标语 | 常驻 "星露谷永远有下一个春天，但现实需要你亲手耕耘每一个明天。" |

**偿债优先级**：
1. 冻结贷款
2. 动态公司 — 剩余天数最少
3. 动态公司 — 本金最高
4. 作物 ID 字母序
5. 固定公司贷款

**退出**：还清所有冻结贷款 → 自动退出破产 → 弹出 "恭喜，享受你的春天吧！"

### 公司倒闭与债券转移

**倒闭条件**：燃料耗尽（fuel = 0）且状态为濒死。

**债券转移**：
- 动态公司倒闭时，所有非冻结贷款转移至贷款利率最高的固定公司
- 转移利率 = 接收方贷款利率 × 折扣（50%）
- 还款周期重置为 28 天
- 转移贷款不计入接收公司额度（IsTransferred 隔离）

**阶梯清算**：

| 倒闭时状态 | 返还比例 | 说明 |
|-----------|---------|------|
| 繁荣 | 80%（可配 0-100%） | GMCM 可调 |
| 稳定 | 50%（可配 0-100%，≤ 繁荣） | GMCM 可调 |
| 饥饿 | 0%（固定） | — |
| 濒死 | 0%（固定） | — |

返还仅针对存款本金，已计利息在倒闭时归零。入股翻倍存款参与返还。

### 入股救市

**触发**：公司首次进入濒死 → 自动进入重组期（初始天数 = 0）。

**百股购买**：
- 弹窗 UI：+/- 选择数量 + 确定/取消
- 每百股价格 = 有效贷款上限 / 7
- 每百股 = 1 天重组期
- 累计上限 7 百股（TotalRescueSharesPurchased 追踪），不可跨日重复购买

**重组期**：
- 燃料不减少（快照恢复机制）
- 濒死限制（禁借贷、限取款）
- 复活条件：燃料满足率回升至 ≥ 80%（稳定期）

**结果**：
- 复活：注资金额 ×2 计入存款本金，状态设为稳定，燃料 100%
- 清算：重组天数耗尽 → 债券转移 + 阶梯清算，入股注资清零

## 进阶玩法

以下策略基于 Mod 各系统的真实数值关系，非设计意图，而是机制自然涌现的结果。

### 杠杆套利

固定公司贷款利率（2.5%-4.0%）常低于动态公司存款利率（5%-33%），产生天然利差。从固定公司借款存入动态公司是基础放大策略。风险点：动态利率会浮动，固定公司到期日固定，一旦还款日现金不足即触发强制划扣。

### 囤货养司

货源紧张时去皮埃尔/Joja 购买对应作物（-5 FP/个），通过出货箱卖出（+10 FP/个），净赚 5 FP/个。成本是购买价与出货价的差额。在濒死期可维持公司存活，等待满足率回升。（待完成）

### 多头对冲

将资金分散存入 3-4 家不同状态的动态公司。繁荣公司吃高息，稳定公司做压舱石，固定公司做流动性储备。任何一家倒闭都不会导致全局崩盘。

### 债券转移套利

当一家持有你高息贷款的公司濒临倒闭时，贷款会转移到固定公司并打五折。此时你欠的利率反而降低了。有意在高息公司借款、诱导（或等待）其倒闭，可获取低成本债务。

### 做空收割

维持一家公司到繁荣期（刷高贷款上限），借满额度，停止出货使其自然衰落到倒闭。借来的钱早已存入其他公司赚取更高利息，倒闭后的债务通过债券转移变成低息长期负债，利差即为收益。

## GMCM 配置

安装 [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) 后游戏内调整，参数 ~50 项，按模块分组：

| 模块 | 关键参数 |
|------|---------|
| 固定公司 | 存贷利率、存贷上限、天气加成 |
| 利率计算 | 单利/复利、负利率开关、运气/天气开关 |
| 动态公司 | 诞生阈值、追踪窗口、R 值系数 |
| 连续售卖 | 加成幅度、上限、衰减幅度 |
| 竞争打压 | 单日最大跌幅、持续天数、最大叠层 |
| 贷款还款 | 宽限期、罚息利率、14 天折扣 |
| 破产欠债 | 收入扣除比例 |
| 债券交易 | 转移利率折扣、新还款周期 |
| 清算返还 | 繁荣/稳定返还比例 |
| 贷款上限乘数 | 四状态独立可配（值 ÷ 10 = 实际乘数） |
| 借款上限 | 杠杆系数 |
| 显示设置 | 利率精度、通知开关 |

## 项目架构

```
DynamicFinancialSystem/
├── BankMod.cs                    入口（组合根，SMAPI 事件适配）
├── Domain/                       值对象（CompanyStatus, InterestCalculationContext）
├── Data/                         数据模型（ModConfig, BankAccountData, DynamicCompanyData, CropDataProvider）
├── Services/
│   ├── Abstractions/             10 个接口
│   └── Core/                     12 个实现（CompanyManager, LoanService, FuelService, BankruptcyHandler 等）
├── UI/                           BankMenu, NumberInputMenu, RescueInvestMenu
├── Patches/                      TVPatch, FbnNewsGenerator
├── assets/                       phone.png, TV1/2/3.png
└── manifest.json
```

**架构原则**：接口驱动（ModServices 手动 DI）· Harmony 最小化（仅 TV 频道）· 持久化安全（调用方统一 Load/Save）· 策略模式（双利率策略）· 零外部 NuGet 依赖
