## 概述

将星露谷物语的出货箱经济扩展为**动态金融投资系统**：

- **手机银行**：随时存取、借贷，查看利率
- **固定公司**：Joja 超市与皮埃尔杂货店提供稳定金融服务
- **动态公司**：每种作物出货达 50 个自动诞生一家公司，利率由作物经济学决定
- **燃料系统**：出货箱加燃料 / 商店买卖扣燃料，满足率决定公司兴衰
- **利率浮动**：天气、运气、连续售卖、停售衰减、竞争对手打压五因子联动
- **破产保护**：强制划扣失败触发，贷款冻结停息，收入 50% 偿债
- **电视金融频道**：FBN 每日预测利率、播报公司诞生、献祭路线影响
- **入股救市**：濒死公司百股购买重组天数，复活翻倍存款

## 快速开始

### 安装

1. 安装 [SMAPI 4.0+](https://smapi.io/)
2. 将 `DynamicFinancialSystem` 文件夹放入 `Stardew Valley/Mods/`
3. （可选）安装 [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) 游戏内调参
4. 启动游戏，拿到手机后右键打开银行

- 第一次进入农场自动收到银行欢迎信，附件含手机
- 手机不可出售、不可丢弃（丢失后次日补发）
- 右键手机 → "进入银行" → 打开金融界面

## 手机银行

### 主界面

- **公司标签页**：顶部切换 Joja / 皮埃尔 / 各动态公司
- **存款区**：显示余额、本金、存款上限、有效利率（悬停看基础值）、累计利息
- **贷款区**：摘要/明细切换，明细视图滚动列表 + 逐条还款
- **操作按钮**：存入、取出、借7天、借14天、还款、明细/摘要、入股救市（濒死时）
- **状态警告横幅**：破产保护（红）、贷款逾期（红）、利息欠债（橙）

### 明细视图

- 点击「明细」→ 最多 2 条贷款 + 滚动条
- 每条显示：编号、周期、到期日、本金、日利率、累计利息、逾期欠息、应还总额
- 每条独立「还款」按钮

### 一键最大按钮

- 借款界面：「最大借款」按钮自动填入上限
- 还款界面：「全部还款」按钮自动填入应还总额

| 公司 | 存款日利率 | 贷款日利率 | 存款上限 | 贷款上限 | 天气偏好 |

## 动态公司

### 诞生条件

- 某作物通过出货箱累计出售 ≥ 50 个（`CompanySpawnRequiredSellCount` 可配）
- 不存在同名活跃公司
- 单季新增上限 2 个，总席位上限 4 个

### 诞生时

- 名称 = 作物名 + "公司"（如"土豆公司"）
- 基础利率由作物 R 值三段式计算
- 初始燃料 = Smax × 30% + 累计出售数 × 10 FP（上限 Smax × 200%）
- 14 天新公司保护期，期间不会触发倒闭

### 存款与取款

- 与固定公司相同的存取界面
- 繁荣/稳定期无限制
- 饥饿/濒死期：**取款受资产池限制**，**禁止借贷**

## 公司状态与燃料

### 状态判定（满足率 = FuelStock / Smax × 10）

| 满足率 | 状态 | 利率乘数 | 贷款上限乘数 | 借贷 | 取款 |
|--------|------|---------|------------|:--:|:--:|
| >150% | 繁荣 | ×1.2 | ×1.0 | ✅ | ✅ |
| 80-150% | 稳定 | ×0.9 | ×0.9 | ✅ | ✅ |
| 30-80% | 饥饿 | ×0.7 | ×0.6 | ❌ | 限资产池 |
| <30% | 濒死 | ×0.4 | ×0.3 | ❌ | 限资产池 |

### 燃料点 (FP)

- 1 个标准作物 = 10 FP，UI 显示为 FP ÷ 10
- **出货箱卖出**：+10 FP（铱星 +20，金星 +15）
- **商店购买/卖出**：-5 FP（打压效果）

### 资产池

- 资产池 = 有效贷款上限 − 未还本金 − 已取额度
- 最大取款 = min(存款余额, 剩余资产池)
- `AssetPoolConsumed` 累计追踪，脱离饥饿/濒死时清零

## 利率体系

### 基础利率

- **固定公司**：从 config 读取
- **动态公司**：R = 等效日收益 / 等效支出（数据源 `Crops values.txt`）
  - 三段式折扣：R>20% 存款×0.5，0<R≤20% 不打折，R≤0 归零
  - 贷款利率 = R>20% 贷款×0.75，否则×1.5，硬上限 15%

### 浮动因子（计算顺序）

1. 从基础利率出发
2. + 连续售卖加成（每连续天 +0.5%，上限 5%）
3. − 停售衰减（每天 −0.5%）
4. − 竞争对手打压（叠层制，每层 −2%/天，持续 5 天，最多 3 层）
5. × 运气倍率（`LuckStrengthCoefficient` 控制）
6. + 天气加成（晴/雨/雪/雷暴，每公司独立）

### 复利

- 仅动态公司享受复利（可配置 `UseCompoundInterest`）
- 固定公司锁定单利

## 贷款系统

### 借款

- 7 天或 14 天周期，14 天享利率折扣（`LongTermRateDiscount`，默认 0.5%）
- 同日同公司同周期自动合并（利率加权平均），不同日独立记录
- 全局上限 = 净资产 × 杠杆系数（`BorrowingLeverageCoefficient`，默认 200%）
- 饥饿期/濒死期/破产保护期间禁止借款

### 还款

- 还款顺序：逾期欠息 → 累计利息 → 本金
- 提前还款：未逾期时重置到期日（续期）
- 逾期部分还款：**不重置到期日**，不清除逾期状态
- 全额还清：贷款移除

### 利息欠债

- 动态公司贷款每日从现金扣息
- 现金不足 → 剩余转入 `OverdueInterest`，进入利息欠债
- 单利模式（默认）：逾期利息不滚入本金
- 复利模式：逾期利息滚入本金利滚利

### 本金欠债

- 固定公司到期无法还款 → 宽限期（`PrincipalDebtGraceDays`，默认 1 天）
- 宽限期内罚息利率（`PenaltyInterestRate`，默认 20%）
- 宽限期结束 → 强制划扣（低利率存款优先）

### 债券转移

- 公司燃料耗尽倒闭时，贷款转给利率最高的固定公司
- 利率 × 折扣（`DebtTransferRateDiscount`，默认 50%）
- 周期重置为 28 天（`DebtTransferNewRepaymentDays`）
- 转移贷款标记 `IsTransferred = true`，不计入接收公司额度

## 破产保护

### 触发

- 贷款逾期 → 宽限期 → 强制划扣（现金 + 全部存款）
- 仍不够还 → 贷款冻结 + 进入破产

### 效果

| 项目 | 状态 |
|------|:--:|
| 冻结贷款计息 | 停止（0%） |
| 冻结贷款到期 | 无限期 |
| 借款 | ❌ 禁止 |
| 取款/存款 | ✅ 正常 |
| 存款利息 | ✅ 正常计算 |
| 收入 | 出货+日间收入的 50% 强制偿债 |
| 标语 | 右下角常驻 "星露谷永远有下一个春天…" |

### 退出

- 还清所有冻结贷款 → 自动退出
- 弹出 "恭喜，享受你的春天吧！"

### 偿债优先级

1. 冻结贷款
2. 动态公司 — 剩余天数最短
3. 动态公司 — 本金最高
4. 按作物 ID 字母序
5. 固定公司贷款

## 公司倒闭与债券转移

### 倒闭条件

- 燃料耗尽（fuel = 0）且状态为濒死
- 注：原 design 的三种条件检测（无交易天数/利率负值/存款枯竭）已移除

### 倒闭清算

- 贷款 → 债券转移至固定公司
- 存款 → 按状态阶梯返还：

| 倒闭时状态 | 返还比例 | GMCM 可配 |
|-----------|---------|:--:|
| 繁荣 | 80% | ✅ |
| 稳定 | 50% | ✅ |
| 饥饿 | 0% | 固定 |
| 濒死 | 0% | 固定 |

- 阶梯校验：稳定期返还 ≤ 繁荣期返还
- 出售计数归零，跨季冷却（同季不再重生）

### 重生

- 继续出货该作物 → 重新达标（50 个）→ 全新公司
- 新公司不继承前身任何数据

## 入股救市

### 触发

- 公司首次进入濒死 → 自动进入重组期
- 初始重组天数 = 0，需玩家购买百股延长

### 百股购买

- 弹窗 UI（+/- 选择数量 + 确定/取消）
- 每百股价格 = 有效贷款上限 / 7
- 每百股 = 1 天重组期
- 累计上限 7 百股（`TotalRescueSharesPurchased` 追踪，不可跨日重复购买）

### 重组期

- 燃料不减少（快照恢复机制）
- 濒死限制（禁借贷、限取款）
- 复活条件：燃料满足率回升至 ≥ 80%（稳定期）

### 复活 / 清算

- 复活：注资金额 ×2 计入存款本金，状态设为稳定，燃料 100%
- 清算：重组天数耗尽 → 债券转移 + 阶梯清算，入股注资清零

```

├── BankMod.cs                    入口（组合根，SMAPI 事件适配）

│       ├── FuelService.cs         燃料 FP 系统
│       ├── BankruptcyHandler.cs   破产管理+偿债优先级
│       ├── ShipmentTrackingService.cs  出货箱监控
│       └── Interest/              固定/动态双利率策略
├── UI/
│   ├── BankMenu.cs                主银行界面
│   ├── NumberInputMenu.cs         数字输入
│   ├── RescueInvestMenu.cs        入股救市弹窗
│   └── ...
├── Patches/
│   ├── TVPatch.cs                 Harmony TV 频道注入
│   └── FbnNewsGenerator.cs        FBN 内容生成器
├── manifest.json
└── assets/
    ├── phone.png
    ├── TV1.png / TV2.png / TV3.png
```

### 架构原则

- **接口驱动**：`ModServices` 手动 DI，所有服务面向接口
- **Harmony 最小化**：仅 TV 频道使用，其余全部 SMAPI 原生事件
- **持久化安全**：方法接收 `BankAccountData` 参数，调用方统一 Load/Save
- **策略模式**：固定/动态公司双利率计算策略
- **零外部依赖**：仅依赖 SMAPI 内置程序集
