# Stage 8 测试流程 — 利息欠债 / 本金欠债 / 破产保护
# 测试日期：2026-05-13
# 前置条件：Stage 1-7 已完成，Build 通过 (0 Error, 1 Warning CS8602)

═══════════════════════════════════════════════════════════════════
📋 测试准备
═══════════════════════════════════════════════════════════════════

1. 确保 BankMod 2.0.0.zip 已部署到 Mods 文件夹
2. 新建测试存档（建议使用 CJB Cheats Menu 快速调钱/调天数）
3. 拿到手机，确认银行界面正常打开
4. config.json 默认值即可测试，建议确认以下关键参数：
   - PrincipalDebtGraceDays: 1     (本金欠债宽限期)
   - PenaltyInterestRate: 0.20     (罚息利率)
   - BankruptcyIncomeDeduction: 0.50 (破产出货扣款比例)
   - UseCompoundInterest: false    (默认单利)

═══════════════════════════════════════════════════════════════════
T1: 动态公司每日扣息 — 现金充足 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 有一个活跃的动态公司贷款（如"土豆公司"）
  - 玩家现金 > 当日应付利息

操作：
  1. 记录当前现金和贷款信息
  2. 睡觉进入下一天
  3. 打开银行界面，查看贷款标签

验证：
  □ 玩家现金减少了当日的贷款利息金额
  □ 贷款"累计未还利息"为 0（日息已现金扣除）
  □ 没有"利息欠债"警告横幅
  □ 聊天框无异常警告消息

═══════════════════════════════════════════════════════════════════
T2: 动态公司每日扣息 — 现金不足 (进入利息欠债) ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 有一个活跃的动态公司贷款（如"土豆公司"）
  - 玩家现金设为 0（或远小于应付利息）

操作：
  1. 把现金花光或用 CJB 设为 0
  2. 睡觉进入下一天
  3. 打开银行界面

验证：
  □ 玩家现金被扣到 0
  □ 贷款"逾期欠息"行出现（红字），金额 = 应付利息 - 原有现金
  □ 银行界面顶部出现橙色警告横幅："⚠ 利息欠债 — 现金不足支付贷款日息，逾期利息持续累积"
  □ 聊天框出现："⚠ 现金不足以支付贷款日息，已进入利息欠债状态。"
  □ 此时仍可存款、取款（未到破产阶段）

═══════════════════════════════════════════════════════════════════
T3: 利息欠债 — 恢复现金后还清 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于利息欠债状态（T2 之后）

操作：
  1. 用 CJB 给自己足够现金
  2. 使用还款功能还清全部欠款（包括逾期欠息）
  3. 睡觉确认不再触发欠债

验证：
  □ 还款时"应还总额"包含 本金+累计利息+逾期欠息
  □ 还款后贷款"逾期欠息"消失（行不显示）
  □ 利息欠债警告横幅消失
  □ 第二天不再出现利息欠债消息

═══════════════════════════════════════════════════════════════════
T4: 固定公司贷款到期无法还款 (进入本金欠债) ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 从固定公司（Joja/皮埃尔）借款，选择 7 天周期
  - 花光现金（金额 < 应还总额）
  - 至少在一个公司有存款（用于测试强制划扣）

操作：
  1. 连续睡觉直到还款日到期（7 天后）
  2. 记录到期日的银行界面状态
  3. 尝试从任何公司借款（应该被拒绝）
  4. 再睡 1 天（宽限期结束，应触发强制划扣）

验证：
  □ 到期日聊天框出现："⚠ 你有贷款已逾期！所有借款功能已暂停，请尽快还款避免强制划扣。"
  □ 银行界面出现红色警告："⚠ 贷款逾期 — 所有借款功能已暂停"
  □ 点击"借7天"/"借14天"按钮 → 红字报错："有贷款已逾期，请先还款恢复借款资格。"
  □ 贷款显示"逾期中！宽限期剩余 1 天"（或 config 设置的天数）
  □ 宽限期结束后：存款被自动划扣（低利率账户优先被扣）
  □ 划扣顺序正确：逾期欠息 → 累计利息 → 本金（从聊天框可见）

═══════════════════════════════════════════════════════════════════
T5: 本金欠债 — 宽限期内手动还款恢复 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于本金欠债状态 (T4)，贷款仍在宽限期内

操作：
  1. 用 CJB 给自己足够现金
  2. 打开银行界面，点击"还款"按钮
  3. 全额还款
  4. 尝试借款确认功能恢复

验证：
  □ 还款后贷款消失（若全额还清）
  □ 本金欠债警告横幅消失
  □ 第二天不再出现逾期消息
  □ 借款功能立即恢复（可正常借7天/14天）

═══════════════════════════════════════════════════════════════════
T6: 破产保护 — 触发条件验证 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 有贷款（任何公司），贷款总额较大
  - 玩家现金不足（现金 < 应还总额）
  - 存款也严重不足（所有存款总额 < 应还总额）

操作：
  1. 确保满足以上条件（建议借一大笔钱然后把钱花光）
  2. 睡觉进入下一天
  3. 观察晨间消息

验证：
  □ 聊天框出现："⚠ 你已进入破产保护状态！所有公司利息已停止，借款和取款功能暂停，每日出货收入的50%将被强制用于还债。"
  □ 银行界面顶部出现红色警告："⚠ 破产保护中 — 利息冻结、取款/借款已暂停，每日出货收入50%用于还债"
  □ 点击"取出"按钮 → 红字报错："破产保护期间禁止取款！请先偿还债务。"
  □ 点击"借7天"/"借14天"按钮 → 红字报错："破产保护期间禁止借款！请先偿还债务。"
  □ 存款利息停止结算（存款余额不增加）

═══════════════════════════════════════════════════════════════════
T7: 破产保护 — 出货收入强制扣款 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于破产保护状态 (T6)
  - 准备一些作物放入出货箱

操作：
  1. 往出货箱放一些高价值作物（如上古水果 × 10）
  2. 睡觉。注意：出货箱收入是第二天醒来才结算的
  3. 第二天醒来，观察晨间消息
  4. 打开银行查看贷款变化

验证：
  □ 聊天框出现类似："破产保护：今日出货收入 XXX g 中扣除 XXX g 用于偿债。"
  □ 扣款金额 = 出货收入 × BankruptcyIncomeDeduction (默认 50%)
  □ 扣款按优先级偿还：逾期欠息 → 累计利息 → 本金
  □ SMAPI 控制台有相应日志输出

═══════════════════════════════════════════════════════════════════
T8: 破产保护 — 还清债务后退出破产 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于破产保护状态 (T6)

操作：
  1. 用 CJB 给自己一大笔钱
  2. 打开银行，点击"还款"，全额还清所有贷款
  3. 确认无任何贷款后睡觉

验证：
  □ 还款后第二天不再出现破产警告
  □ 银行界面顶部红色警告横幅消失
  □ 存款、取款、借款功能全部恢复
  □ 利息正常结算

═══════════════════════════════════════════════════════════════════
T9: 破产 — 存款操作仍允许 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于破产保护状态 (T6)

操作：
  1. 打开银行界面
  2. 点击"存入"按钮
  3. 输入金额，确认存入

验证：
  □ 存款功能正常（破产仅禁止取款和借款，不禁止存款）
  □ 但存入的钱不会产生利息（利息已冻结）

═══════════════════════════════════════════════════════════════════
T10: 还款 — 还款时正确显示逾期欠息 ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 有动态公司贷款，且处于利息欠债状态（OverdueInterest > 0）

操作：
  1. 打开银行界面，切换至该贷款公司
  2. 查看贷款区域
  3. 点击"还款"

验证：
  □ 贷款"逾期欠息：XXX g"行以深红色显示
  □ "应还总额"包含 本金 + 累计利息 + 逾期欠息 三部分
  □ 还款输入框提示的金额正确

═══════════════════════════════════════════════════════════════════
T11: 边界条件 — 单利 vs 复利 (利息欠债) ✅
═══════════════════════════════════════════════════════════════════

前置：
  - 处于利息欠债状态（动态公司贷款，逾期欠息 > 0）
  - config.json 中 UseCompoundInterest = false (默认)

操作 A (单利模式)：
  1. 记录当前的逾期欠息金额
  2. 连续睡觉 3 天（现金保持为 0）
  3. 查看贷款信息

验证 A:
  □ 逾期欠息不会自我增长（每天只增加新的应付日息）

操作 B (复利模式)：
  1. 修改 config.json: "UseCompoundInterest": true
  2. 重新加载游戏
  3. 记录逾期欠息金额
  4. 连睡 3 天
  5. 查看贷款信息

验证 B:
  □ 逾期欠息会自我增长（利滚利效果可见）
  □ 增长速度明显快于单利模式

═══════════════════════════════════════════════════════════════════
T12: 综合流程测试 ✅
═══════════════════════════════════════════════════════════════════

完整走通整个债务漏斗：

  正常状态
    → 动态公司贷款，现金不够付日息 → 利息欠债 (T2)
    → 利息欠债累积，现金仍然不足 → 仍然利息欠债
    → 固定公司贷款到期无法还款 → 本金欠债 + 利息欠债 (T4)
    → 现金不足 + 总存款 < 总债务 → 破产保护 (T6)
    → 出货收入被强制扣除偿债 (T7)
    → 用 CJB 调钱全额还款 → 退出破产 (T8)
    → 恢复正常

验证：
  □ 每个状态转换时聊天框有对应消息
  □ 每个状态在银行 UI 有对应警告
  □ 操作限制按状态正确生效
  □ 无崩溃、无异常 SMAPI 日志
