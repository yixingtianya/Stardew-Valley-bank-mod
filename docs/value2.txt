## 一、利率体系（固定不可改，作为文档展示）

### 1.1 固定公司利率

| 公司 | 存款日利率 | 贷款日利率 | 计息方式 |
|:---|:---|:---|:---|
| 皮埃尔 | **1.5%** | **2.5%** | 单利 |
| Joja | **2.5%** | **4.0%** | 单利 |

- **存款上限**：皮埃尔 1,000,000g / Joja 2,000,000g
- **贷款上限**：皮埃尔 200,000g / Joja 300,000g
- **还款周期**：7天 或 14天（14天周期利率折扣 0.5%）

### 1.2 动态公司利率（根据作物等效支出计算）

**公式**：`等效支出 = 作物售价 ÷ 出种率 × 单次出种数`（加工品不计入）
**基础日利率**：`日收益 ÷ 等效支出`

完整利率数据及燃料参数（Y / D_base / Smax）请参见 `Crops values.txt`，该文件为动态公司利率与燃料参数的唯一数据源。

存款利率衰减规则及贷款利率计算规则见 `架构总.txt` → V3.5 补丁二（利率折扣规则）。

咖啡豆（Coffee Bean）不生成动态公司（见 `架构总.txt` → V3.5 补丁一）。

| 参数 | 设定值 | 说明 |
|:---|:---|:---|
| 固定公司贷款计息方式 | **单利（锁定）** | 不可改为复利 |
| 动态公司贷款计息方式 | **复利** | 仅动态公司享受复利 |

## 三、公司状态与破产概率

### 3.1 状态由燃料满足率区间决定

| 满足率区间 | 状态 | 利率乘数 | 贷款上限乘数 | 日倒闭概率 | 倒闭返还 | 区间特征 |
|:---|:---|:---|:---|:---|:---|:---|
| **>150%** | **繁荣期** | ×1.2 | ×1.0 | **可调（见3.2）** | 80%（可配0-100%） | 窄区间，过度供给 |
| **80% ~ 150%** | **稳定期** | ×0.9 | ×1.0 | **= 繁荣日概率 × 0.3**（联动） | 50%（可配0-100%，≤繁荣期） | **最宽区间**，供需平衡 |
| **30% ~ 80%** | **饥饿期** | ×0.7 | ×0.6 | **5%**（固定） | 0%（固定） | 供给不足 |
| **<30%** | **濒死期** | ×0.4 | ×0.3 | **15%**（固定，重组期冻结） | 0%（固定） | 断供，濒临破产 |

- **繁荣期**：玩家大量超额供应，公司被动扩张，利率最高，但产能过剩风险导致倒闭概率最高。贷款上限维持基准。倒闭返还80%。
- **稳定期**（小资本稳定期）：公司规模适中、经营稳健，利率适中，倒闭概率最低。是新手和保守玩家的避风港。贷款上限维持基准。倒闭返还50%。
- **饥饿期**：货源紧张，贷款上限×0.6，风险急剧上升。取款限制（≤ 资产池余额），禁止借贷，不允许注资。供给不足致死，倒闭返还0%。
- **濒死期**：断供，贷款上限×0.3，进入7天重组倒计时。取款限制（≤ 资产池余额），禁止借贷，允许入股救市（上限=原始贷款上限×50%，复活后翻倍）。重组失败倒闭返还0%。

### 3.2 繁荣期年度倒闭风险（玩家可调，稳定期等比联动）

玩家在配置中选择繁荣期的**年度倒闭风险**，系统自动计算日概率，稳定期日概率随之联动。

| 档位 | 繁荣年倒闭风险 | 繁荣日概率 | 稳定日概率 | 稳定年倒闭风险 | 定位 |
|:---|:---|:---|:---|:---|:---|
| 保守 | 15% | 0.144% | 0.043% | ≈4.7% | 新手友好，稳定期几乎无风险 |
| 均衡 | 22% | 0.218% | 0.065% | ≈7.0% | 略有隐忧 |
| **默认** | **30%** | **0.318%** | **0.095%** | **≈10.1%** | 标准博弈 |
| 激进 | 40% | 0.455% | 0.137% | ≈14.2% | 高端玩家领域 |
| 硬核 | 50% | 0.616% | 0.185% | ≈18.6% | 无绝对安全区 |

- **内部公式**：`日概率 = 1 - (1 - 年风险)^(1/112)`
- **联动规则**：`稳定期日概率 = 繁荣期日概率 × 0.3`，不可单独修改。
- **饥饿/濒死概率固定**：饥饿期 5%，濒死期 15%，不受难度影响。

### 3.3 濒死保护期（最终重组期）

| 参数 | 设定值 |
|:---|:---|
| 触发条件 | 公司首次进入濒死状态 |
| 重组期长度 | **7天** |
| 重组期内倒闭概率 | **冻结为0%** |
| 重组期内利率 | **归零** |
| 重组期内借贷 | **禁止** |
| 重组期结束仍未脱离濒死 | **强制清算倒闭** |
| 玩家可操作 | **入股救市**（规则见第五节） |

追加参数【V3.3.1】：

| 参数 | 设定值 |
|:---|:---|
| 复活后燃料满足率 | 100%（稳定期中部） |
| 入股救市倍率 | 2.0x（注资翻倍进注资公司存款） |
| 入股救市上限基准 | 原始贷款上限（不受状态乘数影响） |
| 濒死期取款 | 限制取款，不超过公司资产池余额 |
| 濒死期注资 | 入股救市，金额 = 原始贷款上限×50%，复活后翻倍计入存款本金 |

## 四、金融频道与真假消息

### 4.1 对外展示规则

- 金融频道每季节**保证至少发生一次真实倒闭风险事件**，其余为烟雾弹。

### 4.2 内部不对外展示的设定

| 参数 | 设定值 | 说明 |
|:---|:---|:---|
| 每季假消息数量 | **2~3条** | 市场传闻，不影响实际倒闭率 |
| 每季真消息数量 | **1条** | 真实危机，当日生效 |
| 假消息触发概率 | 真消息的**2倍** | 玩家无法区分真假 |
| 消息呈现模式 | **三幕剧**（连续3天） | 默认节奏：假 → 随机（50%真/50%假） → 真 |
| 单条消息持续时间 | **仅当天** | 当日风险提升，过夜后恢复 |

### 4.3 消息效果

- **假消息**：纯叙事，不影响公司实际倒闭概率。
- **真消息**：明确指出一家公司，该公司在**当天**倒闭概率从年倒闭率临时提升至 日倒闭率（参考九、配置参数速查总表）（持续至次日凌晨）。若公司幸存，恢复正常概率。
- 玩家**无法通过任何游戏内渠道**区分消息真假，只能观察公司状态变化。

### 4.4 休闲模式

- 配置中可选择 **“关闭自然倒闭风险”**，此时所有状态下的日倒闭概率恒为 **0%**。
- 但**金融频道消息依然会播放**，真消息依然会显示公司名和危机叙事，只是不会实际提高倒闭概率，仅作氛围营造。

## 五、公司破产时的操作限制【V3.3.1 修订】

### 5.1 操作限制总表

| 状态 | 存款 | 取款 | 借贷 | 注资救市 | 救活条件 |
|:---|:---|:---|:---|:---|:---|
| 繁荣期 | 正常 | 正常 | 正常 | - | - |
| 稳定期 | 正常 | 正常 | 正常 | - | - |
| 饥饿期 | 正常 | **限制取款（≤ 资产池余额）** | **禁止** | 不允许 | 燃料满足率 ≥ 80% |
| 濒死期（重组） | 正常 | **限制取款（≤ 资产池余额）** | **禁止** | **允许（上限=原始贷款上限，复活后翻倍计入存款本金）** | 燃料满足率 ≥ 30%（7天窗口） |
| 复活后 | 正常 | 正常 | 正常 | - | 满足率重置为100%（稳定期中部） |

### 5.2 资产池与取款限制

定义：
- 有效贷款上限 = 原始贷款上限 × 状态乘数
- 资产池 = 有效贷款上限 − 已贷出未归还本金总额
- 玩家最大取款额 = min(该玩家存款余额, max(0, 公司当前资产池余额))

资产池变动来源：

| 操作 | 资产池变化 | 说明 |
|:---|:---|:---|
| 玩家存款 | 不变 | 存款增加公司现金，但有效贷款上限不变 |
| 玩家取款 | 不变 | 取款减少公司现金，但不影响有效贷款上限和已贷出本金 |
| 玩家借款 | 减少 | 已贷出本金增加 → 资产池缩小 |
| 玩家还贷 | 增加 | 已贷出本金减少 → 资产池恢复 |
| 公司状态变化 | 随有效贷款上限联动 | 状态恶化 → 有效贷款上限缩小 → 资产池缩水 |
| 注资救市 | +金额 | 直接注入现金，扩张资产池 |
| 每日付息 | 不变 | 利息支付不影响有效贷款上限和已贷出本金 |

### 5.3 入股救市规则【V3.3.1 替换】

- 玩家可向濒死公司注入现金（入股救市）。
- **注资上限** = 公司原始贷款上限 × 50%（不受状态乘数影响）。
- **回报方式**：公司复活后，注资金额翻倍计入该玩家的存款本金。
- **回报生效条件**：公司燃料满足率在7天内回升至 ≥ 30%，脱离濒死。
- **失败处理**：公司倒闭，注资金额与存款一并清零。
- **复活后存款**：翻倍后的存款与普通存款完全相同——享受利率、受限取款规则、承受倒闭清零风险。
- **利率即分红**：翻倍后的存款本金享受公司利率，利率随公司状态波动。
- **防套利**：饥饿期不允许注资，确保套利闭环断裂。
- UI提示词（注资确认界面）："入股救市：注资股份将以翻倍额的形式计入存款，公司复活后生效。"

### 5.4 倒闭存款返还【V3.3.2 新增】

公司倒闭时，根据倒闭时所处状态按比例返还存款本金：

| 倒闭时状态 | 返还比例 | 说明 |
|:---|:---|:---|
| 繁荣期 | 80%（可配0-100%） | 产能过剩致死，返还较高 |
| 稳定期 | 50%（可配0-100%，≤繁荣期） | 随机概率致死，返还适中 |
| 饥饿期 | 0%（固定） | 供给不足致死，清零 |
| 濒死期 | 0%（固定） | 重组期失败，清零 |

- 返还仅针对存款本金，已计入利息在倒闭时归零。
- 入股救市的翻倍存款参与返还计算。
- 返还比例遵循不可逆阶梯：繁荣期 ≥ 稳定期 ≥ 饥饿期（饥饿/濒死固定0%）。
- 返还资金由系统生成，不消耗公司资产池。

## 六、季节初果实购买机制

### 6.1 触发条件

- 每个季节的**前三天**，皮埃尔和Joja会出售一批当季限定果实。
- 售价**显著高于果实基础价值**（皮埃尔加价幅度更大）。

### 6.2 可购买范围

- 已献祭完成或献祭路线不需要的**当季常规作物**。
- **明确排除**：上古水果、杨桃、仙人掌、任何姜岛作物、Sweet Gem Berry等特殊作物。

### 6.3 数量与公司诞生挂钩

| 参数 | 设定值 |
|:---|:---|
| 每季可购买果实总数 | **15~30个** |
| 公司诞生所需累计出售量 | **10~50个**（可配置） |
| 季节初购买量占比 | 占诞生所需数量的 **30%~60%** |

- 玩家购买后通过出货箱售出，可加速对应公司诞生。
- 购买成本较高，玩家需权衡是否愿意为“提前拥有公司”支付溢价。
- 若不购买，也可通过正常种植积累出售量来催生公司。

## 七、公司数量与季节配额

| 参数 | 设定值 | 说明 |
|:---|:---|:---|
| 动态公司总席位上限 | **4个** | 满额后新作物无法生成公司 |
| 单季新增公司上限 | **2个** | 防止前期扎堆出现 |
| 倒闭后冷却时间 | **1个完整季节** | 该公司作物在下一季节无法重新生成 |
| 新公司保护期 | **14天** | 生成后14天内不会触发任何倒闭事件 |

- **季节性封锁**：若公司在其非当季季节倒闭，市场判定该作物本季不受欢迎，必须等到下一个可种植季节冷却才可能解除。

## 八、公司燃料机制（与产能挂钩）

### 8.1 每日燃料需求

燃料需求与玩家该作物的**总种植规模**及**公司当前状态**绑定，而与存款脱钩。

**公式**：`每日需求 = 种植总株数 × 基础维持系数 × 状态系数`

| 作物 | 基础维持系数 | 月产参考 |
|:---|:---|:---|
| 上古水果 | 0.15个/株·天 | 约2.5个/月/株 |
| 啤酒花 | 0.8个/株·天 | 每天可收 |
| 蓝莓 / 蔓越莓 | 0.3个/株·天 | 多次收获 |
| 杨桃 | 0.2个/株·天 | 长周期 |
| 其他常规作物 | 0.15~0.3 | 依生长周期动态 |

| 状态系数 | 繁荣 | 稳定 | 饥饿 | 濒死 |
|:---|:---|:---|:---|:---|
| 乘数 | ×1.0 | ×0.8 | ×0.5 | ×0.3 |

### 8.2 公司生成初始投入

公司诞生时需要一次性向发货箱出售 **10~50个**（可配置）对应作物，作为“创始股本”。此数量不计入日常燃料。

### 8.3 燃料满足率计算

`满足率 = 当日实际供应数 ÷ 需求数`

- 实际供应数：玩家通过出货箱额外运往公司的作物数量（该部分不计入常规售货收入，或仅象征性低价折算）。
- 玩家可故意超额供应将公司推入繁荣期，也可减少供应进行打压。

### 8.4 燃料点（FP）与非对称套利规则【V3.3 新增】

燃料库存内部以"燃料点（Fuel Point, FP）"为单位计算，1 个标准作物 = 10 FP。

| 操作 | 燃料变动（FP） | 说明 |
|:---|:---|:---|
| 出货箱卖出 1 个对应作物 | +10 FP | 标准回补 |
| 出货箱卖出 1 个铱星作物 | +20 FP | 高品质加成（额外 +10） |
| 出货箱卖出 1 个金星作物 | +15 FP | 中品质加成（额外 +5） |
| 在皮埃尔/Joja 购买 1 个对应作物 | -5 FP | 打压（为对家提供渠道） |
| 在皮埃尔/Joja 卖出 1 个对应作物 | -5 FP | 与购买打压等值 |

套利机制：买 10 个土豆（-50 FP）→ 卖 5 个出货（+50 FP）→ 净库存不变，手持 5 个可应对未来危机。打压扣除量（50%）小于回补量，创造囤货空间。

UI 展示：内部 FP ÷ 10 后显示为 1 位小数（个当量）。

### 二、复利机制（更新）

| 参数 | 设定值 | 说明 |
|:---|:---|:---|
| 固定公司计息方式 | **单利（锁定）** | 不可改为复利 |
| 动态公司计息方式 | **复利** | 仅动态公司享受复利 |
| 复利持续时限 | **10~21天**（可配置） | 到期后新增利息转入单利账户，不再滚入本金 |
| **复利冷却时间** | **1个自然年（112天）** | 复利结束后，该公司在一年内无法再次启动复利 |
| 债务计息方式 | **单利** | 利息欠债永不滚入本金 |

**冷却机制详解：**
- 一旦某家动态公司的复利时限到期（例如设定为21天），该公司立刻进入**复利冷却期**。
- 冷却期内，该公司的存款只能按**单利**计算利息。
- 冷却期持续 **112天**（一个完整的星露谷年），到期后自动解除。
- 若该公司在冷却期内倒闭，重新生成的新公司依然需要等待冷却期结束才能开启复利。

**设计意图：**
- 防止玩家在单一公司上无限期吃复利，强制进行战略轮换。
- 玩家必须选择**何时开启复利周期**。是公司刚生成就开？还是养成到繁荣期再开？不同的时机决定了一整年的收益。
- 高端玩家可以在公司濒死、债务转移成功后立刻开启复利，狠狠地收割一波，但这也意味着用掉了该公司今年的复利额度。
- 配合4个公司的总席位，玩家可以规划每年2-3次复利爆发，形成战略节奏。
