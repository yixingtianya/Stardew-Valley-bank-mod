Dynamic Financial System V2.9.0 更新公告
=========================================

各位鹈鹕镇的农场主们，V2.9.0 带来了阶段十四的完整内容：路线完成过场动画、手机网购、破产标语重构，以及大量稳定性修复。


 全新内容

 路线完成与网购

完成 Joja 仓库路线或社区中心献祭路线后，将触发专属过场动画，并解锁手机网购功能。

- Joja 路线：黑屏文字，莫里斯祝贺 + 介绍手机新功能 → 网购解锁
- CC 路线：进入废弃 Joja 超市，皮埃尔讲述电信计划书 →
          五色祝尼魔逐个跳跃出场 → 刘易斯来电话 → 网购解锁
- 电影院已建成的旧存档自动跳过过场，直接解锁网购

 路线效果（存档独立，跨存档不污染）

| 效果 | CC 路线 | Joja 路线 |
|------|--------|----------|
| 公司改名 | Joja超市 → 皮埃尔子公司 | 皮埃尔 → Joja子公司 |
| 打压上限 | 皮埃尔 ×2（6 层） | Joja ×2（6 层） |
| 皮埃尔功能 | 正常 + 季节作物 20 个 | 失去打压 + 季节作物 |
| Joja 功能 | 失去打压 + 季节作物 | 正常 + 季节作物 20 个 |

 手机网购

手机银行界面新增"网购"按钮，可在线访问 6 家商店（CC 路线不含 Joja）。
商店营业时间根据 time.txt 动态检查，休息日/非营业时间显示关闭原因。
沙漠/姜岛需公交/船只解锁后才开放。


 Bug 修复

- 公司改名后贷款不会丢失（贷款记录同步更新公司名）
- 跨存档切换不再出现公司名污染（每次加载从磁盘恢复原始配置）
- 跨存档切换不再误弹"恭喜享受春天"（改为状态变化检测）
- 金融频道不再每天重复播同一条路线新闻
- 同一天反复看 FBN 不再重复触发运气预测算法
- 同季节内公司破产后不会创建同名重复公司
- 姜岛网购不再以邀请信误判为已解锁
- 银行账户数据加载性能优化（内存缓存）


 UI 改进

- 标题栏："Dynamic Financial System by yixingtianya" 同行居中
- 破产标语重构为独立 UI 组件，不再泄漏到游戏截图
- 破产时标语置顶，标题自动下移，布局不重叠
- 银行界面分隔线和内容区跟随动态偏移


 技术改进

- 路线检测 / 事件脚本 / 商店营业时间三层服务独立
- 邮件标记集中管理（MailFlags.cs）
- SMAPI 存档数据隔离（路线状态/网购解锁/打压标记全部存档独立）
- config.json 原始名读取 + 改名恢复机制确保多存档互不污染
